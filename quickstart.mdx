## Prerequisites

Before you begin, you'll need:

- A Vocantly account (sign up or contact [support@vocantly.com](mailto:support@vocantly.com))
- An **App** (create one in the dashboard). Store **App ID**, **public key**, and **secret key** on your **backend** only.
- A modern web browser or Node.js environment

## JavaScript SDK

The easiest way to integrate Vocantly into your application is using our JavaScript SDK.

### Installation

```bash
npm install @vocantly/sdk
```

For **testing** (beta): `npm install @vocantly/sdk@beta`

### Basic Setup

Your **backend** issues an SDK token via `POST /api/v1/apps/:appId/tokens` (JWT or `X-Api-Key` + `X-Api-Secret`). Your **frontend** receives only the **token**—never keys.

```typescript
import { Vocantly } from '@vocantly/sdk';

// Token from your backend—never use keys in the frontend
const client = new Vocantly({
  wsUrl: 'wss://ws.dev.vocantly.com/ws',
  token
});

await client.connect();
```

**Optional (inbox):** To list conversations and fetch message history, add `apiUrl`. With the same token, the SDK will call `GET /sdk/conversations` and `GET /sdk/conversations/:id/messages` using Bearer auth.

```typescript
const client = new Vocantly({
  wsUrl: 'wss://ws.dev.vocantly.com/ws',
  apiUrl: 'https://dev.vocantly.com/api/v1',
  token
});
await client.connect();
const { conversations } = await client.conversations.list({ limit: 50 });
```

### Join a Conversation

```typescript
// Join a conversation to receive messages
await client.conversations.join('conversation-id');

// Get the conversation instance
const conversation = client.conversations.get('conversation-id');

console.log('Joined conversation:', conversation.id);
```

### Send a Message

<Warning>
**Messages are sent exclusively over WebSockets.**

This guarantees ordering, real-time delivery, typing indicators, presence, and receipts.

Use `client.conversations.get(conversationId).sendMessage(content)` to send messages.

REST APIs are used for history, analytics, and internal automation only.
</Warning>

```typescript
// Get the conversation and send a message
const conversation = client.conversations.get('conversation-id');
conversation.sendMessage('Hello, world!');

// Or in one line:
client.conversations.get('conversation-id').sendMessage('Hello, world!');
```

### Receive Messages

```typescript
// Get the conversation and listen for incoming messages
const conversation = client.conversations.get('conversation-id');

conversation.on('message', (message) => {
  console.log('New message:', message.content);
  console.log('From:', message.senderId);
  // Update your UI here
});
```

### Typing Indicators

```typescript
const conversation = client.conversations.get('conversation-id');

// Start typing indicator
conversation.startTyping();

// Stop typing indicator
conversation.stopTyping();

// Listen for typing events from others
conversation.on('typing', (event) => {
  if (event.state === 'start') {
    console.log(`${event.userId} is typing...`);
  } else {
    console.log(`${event.userId} stopped typing`);
  }
});
```

### Presence

```typescript
// Listen for presence updates at the SDK level
client.on('presence', (event) => {
  console.log(`${event.userId} is ${event.state}`);
  // event.state is 'online' or 'offline'
});
```

### Complete Example

```typescript
import { Vocantly } from '@vocantly/sdk';

async function initializeChat() {
  // Token from your backend (POST /apps/:id/tokens)
  const token = await fetch('/api/sdk-token', { credentials: 'include' }).then(r => r.json()).then(d => d.token);

  const client = new Vocantly({
    wsUrl: 'wss://ws.dev.vocantly.com/ws',
    token,
    debug: true
  });

  // Handle connection events
  client.on('connected', () => console.log('Connected!'));
  client.on('disconnected', () => console.log('Disconnected'));
  client.on('error', (err) => console.error('Error:', err));

  // Connect to WebSocket
  await client.connect();
  console.log('Connected to Vocantly');

  // Join conversation
  const conversationId = 'your-conversation-id';
  await client.conversations.join(conversationId);

  // Get conversation instance
  const conversation = client.conversations.get(conversationId);

  // Listen for messages
  conversation.on('message', (message) => {
    console.log('Received:', message.content);
    // Display message in your UI
  });

  // Listen for typing
  conversation.on('typing', (event) => {
    if (event.state === 'start') {
      console.log(`${event.userId} is typing...`);
    }
  });

  // Listen for receipts
  conversation.on('receipt', (event) => {
    console.log(`Message ${event.messageId}: ${event.state}`);
  });

  // Send a message
  conversation.sendMessage('Hello from Vocantly!');

  return client;
}

// Initialize
initializeChat().catch(console.error);
```

## REST API

Use the REST API for reading data and managing resources. **Dashboard** access uses JWT (login/register). **SDK tokens** are issued by your backend via `POST /apps/:id/tokens` (JWT or API key).

### Dashboard authentication (login)

```bash
curl -X POST https://dev.vocantly.com/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "your-email@example.com",
    "password": "your-password"
  }'
```

Response: `{ "access_token", "refresh_token", "user" }`.

### Issue SDK token (backend)

Your backend calls `POST /api/v1/apps/:appId/tokens` with **JWT** or **API key** (`X-Api-Key` + `X-Api-Secret`). See [Issue SDK Token](/api-reference/apps/issue-token). Return the `token` to your frontend; never expose keys.

### Backend integration (external chat)

To add chat to your app (e.g. order chat, appointment chat) **without** dashboard login:

1. **Create conversation** when your business event occurs: `POST /api/v1/conversations/external` with `X-Api-Key` and `X-Api-Secret`. Body: `external_id` (your ID, e.g. order or appointment ID) and `participants` (at least 2; each with `external_user_id`, optional `name`, `email`, `role`). See [Create EXTERNAL (API Key)](/api-reference/conversations/create-external).
2. **Issue SDK token** for the current user: `POST /api/v1/apps/:appId/tokens` with the same API keys and `external_user_id` matching a participant. See [Issue SDK Token](/api-reference/apps/issue-token).
3. **Return** `{ token, conversation_id: data.id }` to your frontend.
4. **Frontend** uses the SDK with `token`, calls `client.connect()`, then `client.conversations.join(conversation_id)` and sends/receives messages.

Same API keys for both steps; no JWT or dashboard session required.

### Make API requests (dashboard)

Use the **access token** in subsequent requests:

```bash
# Get conversations
curl https://dev.vocantly.com/api/v1/conversations \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

# Get messages for a conversation
curl https://dev.vocantly.com/api/v1/conversations/{conversationId}/messages \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

<Note>
**REST API is for reading data only.** Use the SDK for sending messages.
</Note>

## WebSocket Connection

Use the **SDK** (recommended) or connect manually. The **token** comes from your backend; never use keys in the frontend.

```typescript
// SDK (recommended)
await client.connect();

// Or manually (browsers: use Sec-WebSocket-Protocol)
const ws = new WebSocket('wss://ws.dev.vocantly.com/ws', [token]);
ws.onopen = () => {
  ws.send(JSON.stringify({ type: 'join', conversation_id: 'conversation-id' }));
};
ws.onmessage = (e) => console.log(JSON.parse(e.data));
```
