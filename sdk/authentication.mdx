## Overview

The Vocantly SDK uses token-based authentication. You need an SDK token to connect to the WebSocket server.

<Note>
  New to how tokens work? Read [Authentication & tokens](/guides/authentication) first — it
  covers keys vs. tokens and the three ways your backend provisions a token. This page focuses
  on wiring that token into the SDK.
</Note>

## SDK token

You need a single **SDK token** (about 15 minutes lifetime). It is used for both the WebSocket connection and, when you set `apiUrl`, for REST calls (list conversations, fetch messages) as Bearer.

## Authentication Flow

```
1. Your backend calls POST /apps/:id/tokens (JWT or X-Api-Key + X-Api-Secret).
2. Your backend returns the token to your frontend.
3. Frontend initializes SDK with token only—never keys.
4. Connect to WebSocket.
```

<Warning>
**App ID, public key, and secret key are backend-only.** Your frontend never sees them. It receives only the **token** from your backend.
</Warning>

## Getting an SDK Token (Backend)

Your **backend** issues tokens via `POST /api/v1/apps/:appId/tokens`.

### Option A: API key (server-to-server)

```bash
curl -X POST https://dev.vocantly.com/api/v1/apps/YOUR_APP_ID/tokens \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: pk_xxxxx" \
  -H "X-Api-Secret: sk_xxxxx" \
  -d '{
    "external_user_id": "user_123",
    "name": "Jane Doe",
    "email": "jane@example.com"
  }'
```

### Option B: JWT (dashboard user)

```bash
curl -X POST https://dev.vocantly.com/api/v1/apps/YOUR_APP_ID/tokens \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -d '{
    "external_user_id": "user_123",
    "name": "Jane Doe"
  }'
```

**Response:** `{ "token", "expires_in", "user_id" }` — return `token` to your frontend.

## Initialize SDK (Frontend)

```typescript
import { Vocantly } from '@vocantly/sdk';

// token from your backend—never keys
const client = new Vocantly({
  wsUrl: 'wss://ws.dev.vocantly.com/ws',
  token
});

await client.connect();
```

## Token refresh

SDK tokens expire after about 15 minutes. When you get a token-expired error, get a new token from your backend, update the client, and reconnect:

```typescript
client.on('error', (error) => {
  if (error.message?.includes('Token expired')) {
    refreshAndReconnect();
  }
});

async function refreshAndReconnect() {
  const { token } = await fetch('/api/chat/token').then(r => r.json());
  client.updateToken(token);
  await client.connect();
}
```

## Token Claims

The SDK token (issued by `POST /api/v1/apps/:appId/tokens`) contains claims like:

```json
{
  "app_id": "app-uuid",
  "sub": "your-external-user-id",
  "sender_id": "your-external-user-id",
  "name": "User display name",
  "email": "user@example.com",
  "type": "sdk_user",
  "iat": 1234567890,
  "exp": 1234567890
}
```

- `sub` is your app’s user identifier (`external_user_id`). The backend uses it for REST inbox endpoints when you call with Bearer token (e.g. list conversations, fetch messages).
- `type: "sdk_user"` identifies this as an SDK token (not a dashboard JWT).

## Backend Token Exchange Pattern

Your backend calls `POST /apps/:id/tokens` (JWT or API key), then returns the token to your frontend. Frontend never sees keys.

```typescript
// Your backend
app.post('/api/sdk-token', async (req, res) => {
  const user = await verifySession(req); // your auth
  
  const r = await fetch(`https://dev.vocantly.com/api/v1/apps/${process.env.APP_ID}/tokens`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Api-Key': process.env.VOCANTLY_PK,
      'X-Api-Secret': process.env.VOCANTLY_SK
    },
    body: JSON.stringify({
      external_user_id: user.id,
      name: user.name,
      email: user.email
    })
  });
  const { data } = await r.json();
  res.json({ token: data.token });
});

// Frontend: token only, never keys
const { token } = await fetch('/api/sdk-token', { credentials: 'include' }).then(r => r.json());
const client = new Vocantly({ wsUrl: 'wss://ws.dev.vocantly.com/ws', token });
await client.connect();
```
