## Overview

WebSocket connections require an SDK token for authentication. The token is validated on connection and contains user and tenant context.

<Note>
  This page is for connecting to the WebSocket **directly**. If you're using the
  [SDK](/sdk/overview), it handles all of this for you. For how tokens are minted in the first
  place, see [Authentication & tokens](/guides/authentication).
</Note>

## Connection with Token

### Using Sec-WebSocket-Protocol (browsers)

Browsers cannot set custom headers on WebSocket. Pass the token as a subprotocol (from your backend):

```javascript
const ws = new WebSocket('wss://ws.dev.vocantly.com/ws', [token]);
```

### Using Authorization Header (Node.js)

When using a WebSocket client that supports custom headers:

```javascript
const ws = new WebSocket('wss://ws.dev.vocantly.com/ws', {
  headers: { 'Authorization': `Bearer ${token}` }
});
```

### Using Query Parameter

```javascript
const ws = new WebSocket(`wss://ws.dev.vocantly.com/ws?token=${token}`);
```

## Token Validation

The server validates:

1. **Token signature** — Valid JWT signature
2. **Token expiration** — Not expired (e.g. 24h lifetime)
3. **Token type** — SDK token (e.g. `sdk_user`)
4. **App/tenant context** — Valid app and tenant

## Token Claims

```json
{
  "sub": "external_user_id",
  "app_id": "app-uuid",
  "type": "sdk_user",
  "exp": 1234567890,
  "iat": 1234567890
}
```

## Authentication Flow

```
1. Your backend calls POST /apps/:id/tokens (JWT or X-Api-Key + X-Api-Secret)
2. Your backend returns the token to your frontend (never keys)
3. Frontend connects to WebSocket with the token
4. Server validates token → Connection established
5. Token expires → Reconnect with new token from your backend
```

<Warning>
**App ID, public key, and secret key are backend-only.** Your frontend receives only the **token** from your backend. Never expose keys to the frontend.
</Warning>

## Getting an SDK Token (Backend)

Your **backend** issues tokens via `POST /api/v1/apps/:appId/tokens`. See [Issue SDK Token](/api-reference/apps/issue-token).

**API key (server-to-server):**

```bash
curl -X POST https://dev.vocantly.com/api/v1/apps/YOUR_APP_ID/tokens \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: pk_xxxxx" \
  -H "X-Api-Secret: sk_xxxxx" \
  -d '{"external_user_id": "user_123", "name": "Jane", "email": "jane@example.com"}'
```

**JWT:** Use `Authorization: Bearer <access_token>` instead of API key headers. Return `data.token` to your frontend.

## Error Handling

### Invalid Token

```json
{
  "type": "error",
  "error": "Invalid token"
}
```

Connection will be closed with code `1008` (Policy Violation).

### Expired Token

```json
{
  "type": "error",
  "error": "Token expired"
}
```

Connection will be closed. Reconnect with a new token.

## Token Refresh Strategy

Since SDK tokens expire after 15 minutes, implement token refresh:

```javascript
class WebSocketManager {
  private ws: WebSocket | null = null;
  private refreshTimer: NodeJS.Timeout | null = null;

  async connect(token: string) {
    this.ws = new WebSocket('wss://ws.dev.vocantly.com/ws', {
      headers: { 'Authorization': `Bearer ${token}` }
    });

    this.ws.onopen = () => {
      // Schedule token refresh 1 minute before expiry
      this.scheduleRefresh(14 * 60 * 1000);
    };

    this.ws.onclose = (event) => {
      if (event.code === 1008) {
        // Token invalid/expired, get new token and reconnect
        this.handleTokenExpired();
      }
    };
  }

  private scheduleRefresh(delay: number) {
    this.refreshTimer = setTimeout(async () => {
      const newToken = await this.fetchNewToken();
      await this.reconnect(newToken);
    }, delay);
  }

  private async handleTokenExpired() {
    const newToken = await this.fetchNewToken();
    await this.connect(newToken);
  }

  private async fetchNewToken(): Promise<string> {
    const response = await fetch('/api/sdk-token', { credentials: 'include' });
    const { token } = await response.json();
    return token;
  }

  private async reconnect(token: string) {
    if (this.ws) {
      this.ws.close();
    }
    await this.connect(token);
  }
}
```

## Using the SDK

Use the **token** from your backend only—never keys:

```typescript
import { Vocantly } from '@vocantly/sdk';

// token from your backend (POST /apps/:id/tokens)
const client = new Vocantly({
  wsUrl: 'wss://ws.dev.vocantly.com/ws',
  token
});

await client.connect();

client.on('error', async (error) => {
  if (error.message?.includes('Token expired')) {
    const newToken = await fetch('/api/sdk-token', { credentials: 'include' }).then(r => r.json()).then(d => d.token);
    client.updateToken(newToken);
    await client.connect();
  }
});
```
